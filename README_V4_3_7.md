# 名刺管理PWA v4.3.7 — グループ細分化抑制版

## 修正対象

OCRのbboxサイズ差によって、本来1つの文字列が細切れになる問題を修正しました。

例:

トヨタ自動　車　株式会　社

旧版では `車` や `社` のbbox高さが小さく認識されると、
文字サイズ差としてグループが分割される場合がありました。

## v4.3.7の文字サイズ判定

### 旧方式
1語だけサイズが異なれば分割候補。

### 新方式
通常のサイズ差は「2語以上連続」した場合だけ分割します。

つまり:

24px → 15px → 24px

のような一時的変動はノイズとして無視します。

一方、

28px → 18px → 18px → 19px

のように小さい文字が継続した場合は
本当にフォントサイズが切り替わったと判断して別グループにします。

## 1文字の日本語への特別処理

`車` `社` `部` など1〜2文字の日本語tokenは
OCR bboxのサイズ誤差が大きいため、さらに分割しにくくしています。

単独tokenで分割するのは、約2倍以上の極端なサイズ差がある場合だけです。

## 期待結果

トヨタ自動 / 車 / 株式会 / 社

↓

トヨタ自動車株式会社

として同一グループに残ります。

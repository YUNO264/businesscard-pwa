# 名刺管理PWA v4.3.4 — グループ内2行の読取順修正版

## 修正した現象

例:

営業本部　東京支店
東京営業二課　販売主任

旧版では、2行を1行として扱ってX座標順に並べる場合があり、

営業東京本部営業東二京課販売支点主任

のように上下2行が混ざることがありました。

## v4.3.4の処理

グループ内でも文字座標からもう一度行構造を作ります。

1. 各OCR文字/単語の中心Y座標を取得
2. 中心Y座標の中央値を基準に行クラスタリング
3. 行1を左 → 右
4. 行2を左 → 右
5. 行を上 → 下の順で連結

上記例は

営業本部東京支店東京営業二課販売主任

の順になります。

## 重要な変更

従来は行クラスタの外接矩形が大きくなると、
次の行まで連鎖的に同じ行へ吸収する可能性がありました。

v4.3.4では、外接矩形ではなく
「その行に所属する文字の中心Y座標の中央値」を行の基準位置にしています。

そのため、近接した2行でも混ざりにくくなっています。

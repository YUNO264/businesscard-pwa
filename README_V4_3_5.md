# 名刺管理PWA v4.3.5 — OCR空白除去版

## 修正内容
OCR後の文字列に不要な空白が入る問題を修正しました。

削除対象:
- 半角スペース
- 全角スペース
- タブ
- NBSP等のUnicode空白

## 対象
- OCRグループ内文字列
- 部署
- 役職
- 会社名
- 氏名
- 電話
- 携帯
- メール
- 郵便番号
- 住所
- Web
- OCR全文表示

OCR全文については改行だけ残し、各行内の空白を削除します。

例:

営業本部　東京支店
東京営業二課　販売主任

↓

営業本部東京支店
東京営業二課販売主任

グループ化結果:

営業本部東京支店東京営業二課販売主任

v4.3.4までの行順修正、JS傾き補正、縦書き対応はそのまま維持しています。

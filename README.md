# 名刺管理PWA v4.2 — 横書き・縦書き対応

## 追加機能
- OCR方向を「自動判定 / 横書き / 縦書き」から選択
- 縦書き専用 `jpn_vert` 学習データを追加
- 自動判定では通常の横書きOCRを先に実行し、結果が不安定な場合だけ縦書きOCRも実行して比較
- 横書き読取順: 上 → 下、同じ行は左 → 右
- 縦書き読取順: 右列 → 左列、各列は上 → 下
- OCR領域番号も選択した文字方向に合わせて付番
- 自動判定が外れた場合は「縦書き」を指定して再OCR可能

## 初回 / 更新時
1. ZIPを展開
2. `SETUP_OCR_FINAL.bat` を実行
3. v4.1以前のサイトデータ / Service Workerを削除
4. VS Code + Live ServerまたはGitHub Pagesで起動
5. 設定 → OCR資材を確認
6. `Japanese Vert: OK` を確認

## 注意
縦書き氏名で姓と名の間に空白がない場合、姓・名の自動分割は完全にはできません。
OCR後にフォームで修正してください。

名刺画像やOCR結果は外部OCR APIへ送信しません。

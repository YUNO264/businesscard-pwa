# 名刺管理PWA v4.3.6 — 文字サイズ差によるグループ分割

## 追加した条件

同じ行・近い位置にある文字でも、文字サイズが明確に異なる場合は
別グループへ分割します。

横書き:
- OCR bboxの「文字高さ」を文字サイズとして使用

縦書き:
- OCR bboxの「文字幅」を文字サイズとして使用

## 判定方法

現在グループに入っている文字サイズの中央値と、
次に追加しようとしている文字サイズを比較します。

次の両方を満たす場合にグループを分割します。

- サイズ比 1.35倍以上
- 絶対差 4px以上

例:

営業本部     TOKYO BRANCH
  28px          18px

→ 文字サイズ差が大きいため別グループ

## なぜ直前文字ではなく中央値か

漢字は「口」「一」「営」など文字形によってOCR bbox高さが多少変動します。
直前1文字との比較だけでは誤分割が増えるため、
グループ内の文字サイズ中央値を基準にしています。

## 既存条件との関係

グループ境界は以下のいずれかで発生します。

1. 横方向/縦方向の間隔が大きい
2. 住所・TEL等への意味切替がある
3. 文字サイズが明確に変わる ← v4.3.6追加
